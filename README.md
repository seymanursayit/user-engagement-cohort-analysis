# User Engagement & Cohort Retention Analysis

## Project Overview

This project analyzes user engagement and retention using Google Sheets. It focuses on understanding user activity over time, measuring engagement, forecasting active users, and evaluating user retention through cohort analysis.

## Objectives

- Analyze user age distribution and variability.
- Calculate Daily Active Users (DAU) and Weekly Active Users (WAU).
- Measure user engagement using the DAU/WAU ratio.
- Forecast future WAU values using spreadsheet functions.
- Prepare activity data using text and date functions.
- Build cohort tables and analyze user retention rates.
- Visualize user activity and retention patterns.

## Tools & Skills

- Google Sheets
- Spreadsheet formulas and functions
- Pivot tables
- Data cleaning and transformation
- DAU and WAU analysis
- Forecasting
- Cohort analysis
- Retention rate analysis
- Data visualization

## Key Metrics

| Metric | Description |
|---|---|
| DAU | Daily Active Users |
| WAU | Weekly Active Users |
| DAU/WAU | Engagement stickiness ratio |
| Retention Rate | Percentage of users who return after their initial activity period |
| Cohort | A group of users grouped by their first activity month |

## Key Learnings

This project provided practical experience in analyzing user engagement, preparing activity data, forecasting active users, and evaluating retention patterns using cohort analysis.
